# What "done" looks like

A system that takes a patient narrative and returns ranked trials, each with per-criterion
`satisfied` / `violated` / `unverifiable` labels and verbatim grounded evidence — plus a results table
showing all five ladder rungs on held-out topics under both metric families, and an error taxonomy for
the medically-relevant-but-excluded case.

The minimum publishable result is narrower and worth naming: **the ladder measured honestly, with the
forced-choice ablation showing whether three-state labelling earns its complexity.** Even if eligibility
reasoning does not improve nDCG, a well-measured reduction in exclusion contamination answers the
research question.

See [11 — Ablation study, error analysis, write-up](11-ablation-writeup.md) for the phase that produces
this, and [research edge](research-edge.md) for where the contribution beyond "done" can live.
